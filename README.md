# Shadowfall: Red Ties

A keyboard-first 2D fighting game set on the Bamboo Frontier.

## Run

Open `index.html` in a browser. No build step or external game assets are required.

## Controls

- Solo: `Enter` jump, `Space` punch. Fighters close distance automatically.
- Two player: Player 1 uses `Enter` jump and `Space` punch. Player 2 uses `Ctrl` jump and `Alt` punch.
- Defeat 10 increasingly difficult, always beatable levels.
